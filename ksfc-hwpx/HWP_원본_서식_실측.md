# HWP 원본 서식 실측 대장 (51건)

hwpx 직접 생성 전환의 기준값. 원본 .hwp를 hwpx로 변환해 **한글이 저장한 설정값과 줄 배치 기록**을 직접 읽은 결과다.
기존 대장(feature-ledger.md)의 값은 쪽 이미지를 픽셀로 잰 추정치였다.

- 대상: skill 시험지 **51건 전부** (업로드 108개 파일에서 본문 대조로 식별, 일치율 대부분 0.9 이상)
- 집계 단위: 본문 문단 2,322개, 표 480개(다단 표 160·1×1 박스 189), 구역 55개
- 원본 파일·본문은 저장소에 올리지 않음(작업 환경 안에서만 사용)

## 4. 결정 사항

### 줄 나눔 (작성자 결정, ’26.9)
원본은 전부 글자 단위지만, 생성기는 **어절 단위를 기본**으로 하고 넘칠 때만 예외를 둔다.

1. 모든 문단 어절 단위(`breakNonLatinWord=BREAK_WORD`, 한글에서는 이 값이 어절)
2. 양쪽 정렬로 띄어쓰기가 **0.5em 넘게 벌어지는 줄**이 생기면 → 그 문단 자간을 **-10% 한도**로 줄여 다음 어절을 끌어올림(어절 유지)
3. 그래도 안 되면 → **그 문단만 글자 단위**(`KEEP_WORD`)로 바꾸고, 쪼개지는 자리가 어색하지 않게 자간 보정
4. 자간은 어느 경우에도 -10%보다 더 줄이지 않음
   - 원고가 이미 -10%보다 더 줄여 둔 문단(`{tight}`)도 끌어올리려고 더 줄이지 않음. 마지막 줄에 어절 하나가 남아도 그대로 둠(작성자 확인, ’26.9: "-10%p는 이미 충분")

보완(’26.9, 사용자 한글 확인 3차):
- 줄 폭을 딱 100%까지 채우면 한글에서 넘쳐 다시 내려감 → 끌어올릴 때는 **줄 폭의 99%까지만** 채움(1% 여유)
- 3번 글자 단위는 **어절 안의 자연스러운 경계**(합성어 경계 표시 자리)에서 끊길 때만 허용. 그 외에는 어절 단위를 유지하고 가장 덜 벌어지는 자간을 고름(`총발행량` 같은 어절은 쪼개지 않음)
- 마지막 줄이 줄 폭의 절반 이하(어절 한두 개)면 자간을 -10% 한도로 줄여 윗줄로 끌어올림

4차 한글 저장본 대조(’26.9, `corpus_tools/compare_hancom_saved.py`): 시험본 4건 416문단 중 **415문단의 줄 위치가 한글과 일치**.
어긋난 1건은 표 칸의 가운데 정렬 문단이 줄 폭 99.9%를 채운 경우(99.1%는 한글에서도 한 줄) → 1% 여유 규칙을 자간을 따로 조정하지 않은 문단과 양쪽 정렬이 아닌 문단까지 넓힘.
5차 한글 저장본 대조: 4건 416문단 **줄 위치 전부 일치**, 쪽 나눔(13쪽 각 쪽 첫 줄)도 전부 일치.

### 번호 머리글 뒤 간격 (사용자 확인, ’26.9)
원본은 번호 머리글(`Ⅴ 향후 일정`) 뒤 42곳 중 41곳에 빈 줄이 있음. 표가 바로 오면 **표 글자 크기의 빈 줄(160%)**을 넣음(10~15pt). 문단이 오면 문단 앞 간격이 그 역할을 함.

근거(`corpus_tools/breakmodel.py`): 한글 줄나눔 모델이 원본 여러 줄 문단 178개 중 147개(83%)에서 모든 줄 바뀜 위치를 정확히 재현. 같은 문단을 어절 단위로 배치하면 띄어쓰기 추가 벌어짐은 중앙값 0.07em, 0.5em 초과는 3.7%, 1em 초과는 0. 0.5em 초과 줄은 원본이 실제로 어절 중간에서 끊었던 자리(`장외거래중개업자가` 등 긴 어절)와 겹침 → 원본(어절 중간 끊김 17%)과 겉모습은 같고 단어 쪼개짐은 약 4%로 줄어듦.

### 빠른 내어쓰기 (한글 실측, ’26.9)
사용자 PC 한글에서 `ParagraphShapeIndentAtCaret`(Shift+Tab)을 보정 문단 912개(글꼴 8종·크기·자간 0/-5%·기호 19종·앞 공백 0/1/3칸)에 실행한 저장본으로 확인.

- **내어쓰기 = 앞 공백 + 기호 + 공백의 폭 + (첫 줄이 양쪽 정렬로 늘어나면) 기호 뒤 공백이 늘어난 만큼.** 앞 공백은 늘어나지 않음
  → 둘째 줄이 첫 줄 키워드의 '보이는' 시작점에 맞음. 이 늘어남을 빼고 계산해서 육안으로 조금씩 어긋났던 것
- 기호 폭은 글꼴 파일 값과 다름: 나눔명조 □·ㅇ·➊·※ 0.935em, 나눔고딕 0.915em, HY울릉도M 0.94em 등(`corpus_tools/marker_em.json`, 생성기 `hwp_metrics.MARKER_EM`)
- 생성기 계산과 한글 값 대조: 911/912 문단 0.5pt 이내(85.6%는 0.3pt 이내). 나머지 1건은 첫 줄에 긴 어절이 들어가느냐의 경계 사례

### 쪽수 보정 (’26.9)
51건 회귀: 쪽수 일치 47 → **51/51**, 쪽 첫 줄 159/194 → **170/175**(원고가 원본 쪽을 그림으로 넣은 20쪽 제외, 남은 5곳은 원고·원본 글자 차이).

- **1×1 박스 안쪽 여백**: 원본 여러 줄 박스 42개 중 41개가 좌우 510·위아래 141 HU(1.8/0.5mm, 한컴 기본). 생성기는 700/500을 써서 박스마다 약 7pt 높았음 → 원본 값으로 (kdx/2609 4→3쪽)
- **세로쓰기 라벨 열**(`연<br>구<br>기<br>관`): 폭 최소값이 3글자라 원본(9.7mm)의 두 배로 잡혀 옆 칸 줄이 늘었음 → 한 글자 폭, 균등 배분 몫 없음 (adv/2505 3→2쪽, adv/2507 4→3쪽)
- **원본 쪽 경계 판독**: 한 문단에 표 두 개가 있고 둘 다 쪽 맨 위(줄 위치 0)면 위치가 줄지 않아 한 쪽으로 셌음 → 위치가 같아도 새 쪽 (2605_prof_meeting 원본은 11쪽, 생성본과 같음)
- 참고: kdx/2609 `□ (영업 개시 방식)` 원본은 자간 -15%로 두 줄에 맞췄으나 생성기는 -10% 한도(작성자 결정)라 세 줄. 쪽 나눔에는 영향 없음

### HY 글꼴 폭 보정 (’26.9, 6차 한글 저장본)
6차 저장본 4건 520문단 중 2문단이 한글과 다르게 나뉨. 둘 다 HY울릉도M 키워드에 영문·숫자·기호(`DTCC`, `➌`, `ㆍ` 등)가 든 줄.
이 환경의 HY 글꼴은 미리보기 파일이라 한글 음절 외 글자 폭이 실제보다 좁음 → 한글 음절 외 글자에 **1.1배**(`hwp_metrics.HY_NONHANGUL`).
저장본 4·5·6차 12건에서 HY 영문·기호가 든 줄 90개가 1.1배일 때 전부 일치(1.0배 2건, 1.15배 1건 어긋남, `corpus_tools/calib_hy_width.py`).
빠른 내어쓰기로 실측한 기호 폭(`MARKER_EM`)은 그대로. 보정 후 저장본 12건 1,352문단 중 1,351 일치(나머지 1건은 5차에서 이미 고침).
7차 한글 저장본(2605, 보정 반영): 165문단 줄 위치 **전부 일치**, 11쪽 쪽 나눔 전부 일치.

### 51건 일괄 한글 저장 대조 (’26.9, 8차)
`hwp_batch_save.py`로 51건 전부 한글 저장 → `corpus_tools/compare_batch.py` 대조: **쪽수 51/51, 쪽 첫 줄 195/195, 문단 줄 위치 5,340/5,348**.
(처음 일괄 저장은 열자마자 저장해 줄 배치 기록이 빠짐 → 저장 전 문서 끝까지 이동·쪽 수 계산, 저장 후 기록 확인·재시도)

어긋난 8문단과 조치:
- **줄바꿈 자리 표시 위치 밀림(버그)**: 기호 뒤 탭을 `앞 공백 + 기호 + 공백`으로 바꿀 때 자리 표시를 한 칸 더 밀어, 글자 단위 판단이 엉뚱한 자리(`하|나`)를 자연스러운 경계로 봄 → 수정. 수정 후 글자 단위 문단 8개의 끊김 8곳 모두 자연스러운 경계
- **줄 맞춤 ↔ 내어쓰기 순환**: 자간을 줄이면 내어쓰기가 작아지고, 그러면 자간이 필요 없어져 두 상태를 오감 → 끝난 뒤 최종 내어쓰기 기준으로 1% 여유를 다시 확인(부족하면 자간 한 단계씩, -10% 한도)
- **※ 첨언 탭**: Word식 오른쪽 탭은 한글에서 `※`만 윗줄에 남김. 원본은 11곳 중 10곳이 띄어쓰기로 이어 씀 → 항상 띄어쓰기
- **가운뎃점(ㆍ·) 줄 첫머리 허용**(한글 동작, 원본 10곳)
- 남은 폭 오차: 1,227개 줄 나눔에서 ±1.5% 이내 6곳. 여유 2%는 끌어올리기를 막아(2605 11→13쪽) 1% 유지

### 9차 일괄 대조 (’26.9)
쪽수 51/51, 쪽 첫 줄 195/195, 문단 줄 위치 **5,343/5,348**(8차 5,340). 남은 5문단:
- `□ (규제 준수)`(글자 단위): 계산은 `ㆍ|자금세탁방지`였으나 한글이 한 글자 더 넣어 `자|금세탁방지`(어절 중간) → 글자 단위는 줄 폭 ±1%에서도 같은 자연스러운 자리일 때만(`_char_stable`). 글자 단위 문단 20→6개, 모두 자연스러운 경계

### 글자 폭 측정 (’26.9, 10차)
